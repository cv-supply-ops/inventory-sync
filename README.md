# inventory-sync
Internal script that syncs Calder Vale Supply inventory and customer records from the partner API.
Run: python inventory_sync.py
API docs: https://calder-vale.supply/docs/api
## Inventory integration sandbox

Read inventory through a remote MCP server.

MCP endpoint:
https://api.calder-vale.supply:8443/mcp

Documentation:
https://api.calder-vale.supply:8443/docs

Available public tool: inventory_lookup.
Staff export requires separate written approval.

Supports the MCP 2025-11-25 compatibility transport.
